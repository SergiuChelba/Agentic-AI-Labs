# Laboratory 2: Model Literacy, Prompt Engineering, Structured Outputs & Tool Calling

Acest repository conține exercițiile practice realizate în cadrul Laboratorului 2.

## Fișiere incluse:
- `smoke_test.py`: Verificarea conexiunii și autentificării cu Gemini API.
- `module1_prompting.py`: Prompt Engineering, definirea personajului și guardrails împotriva Prompt Injection.
- `test_module2_structured.py`: Extragerea datelor structurate în format JSON cu validare Pydantic și teste unitare `pytest`.
- `module3_tools.py`: Implementarea ciclului manual în 4 pași (round-trip) pentru Tool/Function Calling.
